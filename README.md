# 🌿 Personal Portfolio Website
🔗 **[Visit My Portfolio](https://nimrarazzaq346.github.io/codealpha_myportfolio/)**
Welcome to my Personal Portfolio Website! This project showcases my skills, projects, experience, and contact information through a clean, modern, and responsive design.

## 📌 About the Project

This portfolio website is designed to introduce me as a Computer Science student and aspiring web developer. It provides visitors with an overview of my technical skills, completed projects, and ways to connect with me.

The website focuses on a user-friendly interface, attractive visuals, smooth navigation, and responsive layouts.

## ✨ Features

- **Home Section:** Introduction and welcome message.
- **About Me:** Personal introduction and background.
- **Skills Section:** Highlights technical skills and technologies.
- **Projects Section:** Displays completed projects with descriptions.
- **Resume Section:** Provides access to my resume.
- **Contact Section:** Allows visitors to connect with me.
- **Responsive Design:** Compatible with different screen sizes.
- **Smooth Scrolling:** Easy navigation between sections.
- **Hover Effects & Animations:** Enhances the user experience.

## 🛠️ Technologies Used

- **HTML5** – Website structure.
- **CSS3** – Styling, layouts, animations, and responsiveness.
- **JavaScript** – Interactive elements and navigation.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Extract the project folder if downloaded as ZIP.
3. Open the folder in Visual Studio Code.
4. Open `index.html` in your browser.
5. Explore the portfolio website.
